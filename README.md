# 🧠 LeetCode Solutions

Este repositório contém minhas resoluções de problemas da plataforma [LeetCode](https://leetcode.com/u/digooow/), desenvolvidas como parte da minha jornada de aprimoramento em **algoritmos** e **estruturas de dados**.

## 🎯 Objetivos
- Fortalecer a lógica de programação e o raciocínio computacional.
- Praticar a sintaxe e os recursos da linguagem **C++**.
- Me preparar para desafios técnicos e processos seletivos na área de desenvolvimento.

## 🗂️ Estrutura
Os códigos estão organizados por nome do problema ou por tópico (em breve). Atualmente, conto com:

- `TwoSum.cpp` – Resolução do clássico problema "Two Sum" (nível: Fácil).

## ⚙️ Tecnologias
- Linguagem: **C++**
- Compilador: compatível com C++17/20
